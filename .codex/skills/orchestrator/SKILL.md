# Orchestrator

Read repository instructions and classify the requested deliverable. Keep Codex as owner with the active model and user-selected settings. Use the relevant floorX domain skill; avoid loading every skill.

Handle narrow work directly. For a consequential ambiguity or independent review, optionally use consult-claude or consult-antigravity with a bounded, read-only request when available and authorized. Preserve the user's constraints, share only necessary context, verify advice locally, and continue without repeated retries if the consultant is unavailable. Do not delegate greetings or trivial lookups.

Planning, analysis, and preparation requests end with verified documents/configuration/skills within their scope. They do not authorize application implementation. An explicit implementation request authorizes its stated work without another confirmation step.
