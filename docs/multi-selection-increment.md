# Milestone C increment: multi-selection and clipboard editing

The planner supports selecting several fixtures by Shift-clicking on the canvas or in the fixture list. Cmd-click on Mac and Ctrl-click on Windows also toggle a fixture. Cmd/Ctrl+A selects all fixtures. Clicking an unselected fixture starts a new selection; clicking one selected member keeps the group available for dragging and a completed click reduces the selection to that fixture. Escape clears the selection.

Dragging any selected fixture moves the whole selection by the same offset. Selected fixtures have individual dashed outlines, while the canvas focus outline is suppressed when a selection exists. The preview stays outside the saved document until mouse release. The completed group move is one validated document edit and one Undo step; Escape cancels it. Resize and rotate handles remain available only for a single selected fixture. There is no group pivot or group scale/rotation in this increment.

Copy, Paste, Duplicate and Delete buttons act on the full selection. Cmd/Ctrl+C, V and D are equivalent, and Delete/Backspace removes the selection. The clipboard is internal to the editor tab and is not persisted or written to the operating-system clipboard. It captures fixture dimensions, rotation, properties and the exact versioned definition snapshots. Pasting after loading another layout adds missing definitions and rejects a conflicting snapshot with the same ID/version. Duplicate offsets copies by 0.5 m in X and Z; successive pastes from one copy move another 0.5 m each time. New fixtures receive fresh IDs. Each duplicate, paste or group delete is one undoable edit, and invalid IDs or positions leave the document unchanged.

The store tests cover multi-selection toggling, group move preview/cancel/undo/redo, fresh IDs, definition snapshots across a layout load, repeated paste offsets and atomic failure. Browser checks confirmed Shift-selection in the list, Cmd+A, group drag with both positions changing, one-step Undo, toolbar Duplicate, and toolbar Copy/Paste. Browser automation intercepted the operating-system paste shortcut before the page received it, so Cmd/Ctrl+C and V still need a manual browser check.
